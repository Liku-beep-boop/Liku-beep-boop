## About me

I build **REST APIs and backend services** with Node.js and NestJS — authentication with JWT, relational data modeling with PostgreSQL/MySQL, and documented endpoints with Swagger/OpenAPI.

I also enjoy shipping small, useful tools that solve real problems for non-technical users: Windows desktop apps in C#/.NET and Python, and static sites that people can edit themselves.

- 🔭 Currently working on **[Kip](https://github.com/Liku-beep-boop/kip)**, an always-on-top sticky notes app for Windows (WPF / .NET 10)
- 🌱 Interested in API design, clean architecture and local/offline-first AI tools
- ☕ Powered by APIs & coffee
